# Test plans

Test plans for the Allocations dashboard, written by the Playwright planner
agent against dashboard-s on 2026-10-30. Each scenario is tagged "verified
live" or "derived from code". Live findings take precedence over the code.

The plans refer to the allocations that existed on dashboard-s when they
were written (for example 152181 and 152182). Tests create their own
`pwtest-` allocations instead; see `../README.md`.
